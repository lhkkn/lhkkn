# Kevin Phien Le

**Film producer & software engineer — AI-native systems.**

I produce feature films and build the AI-native tooling that runs them.

## What I'm building

**[Méliès](https://melies.kinoism.com)** — a production-management platform (scheduling, treasury, budgeting, contracts) that I developed while producing my own features and iterated on live shoots. React + TypeScript front end, Python back end, ~800 tests. *Live demo — one click, no login needed.*

**[conductor-mcp](https://github.com/lhkkn/conductor-mcp)** — a dependency-free MCP server, hand-rolled in the Python standard library, that lets AI agents read a software workspace (project inventory, context assembly, drift detection). The extracted, runnable core of a larger personal control plane.

**[Kinoism](https://kinoism.com)** — a live cinema showtime platform across 22 theaters in NYC and LA.

## Background

Six years building accounting and trading systems in crypto finance — a hedge fund, then Kraken — before producing two self-financed features. I work at the intersection of film production and AI tooling: most engineers haven't been on a set; most filmmakers can't build the software.
